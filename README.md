# Chart-VIP

Chart-VIP is a browser-based interactive visualization project designed to render and interact with educational or performance metrics. It is structured with HTML, CSS, and JavaScript modules for a clean and responsive frontend experience.

## Features

- Dynamic chart rendering
- Event-driven UI updates
- Modular JavaScript architecture
- JSON-based data integration

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge)
- No server required — runs locally

### Running the Project

1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Interact with the dashboard as needed.
